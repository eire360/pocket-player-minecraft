# Pocket Player for Minecraft

Custom Fabric mod adding a modeled, craftable iPod with live LCD and controls linked to the Mac Music app.

## Download

[Download source ZIP](https://github.com/eire360/pocket-player-minecraft/archive/refs/heads/main.zip)

## Setup

Requires Apple Silicon macOS, Minecraft 26.3, Fabric, and Java 25.

- `Source/src/`: Minecraft mod.
- `Source/native/`: Mac Music helper.
- `Source/tools/`: build and mesh utilities.

The build utilities currently require local Minecraft libraries; a self-contained installer is not included.

In-game, obtain Pocket Player iPod from Creative → Tools & Utilities, or craft it with iron/glass/iron, iron/redstone/iron, empty/iron/empty. Hold it and press R, choose Connect Music, then allow macOS Music automation. Playback is local to your Mac.

## Controls

Scroll/drag the wheel to navigate, Enter to select, Backspace/Menu to go back, Space to play/pause, and side buttons to skip.
